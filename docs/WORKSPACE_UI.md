# 统一工作台界面

## 范围与方案

以最新版历史交易页面为视觉标准，保留五组左侧导航，使用现有日夜主题变量、醒目的等宽数字、紧凑筛选条、小箭头折叠和独立错误提示。没有引入新的 UI 库、构建工具或外部统计服务。

共享实现：`templates/components/workspace.html`、`static/workspace.css`、`static/workspace.js`，样式只作用于 `.jx`。历史交易不加载这套样式，保持原布局；共享自动刷新只做兼容性修正。

## 展示字段与数据来源

| 展示项 | 数据来源 | 展示限制 |
|---|---|---|
| 权益、可用余额 | EquitySnapshot 最新数据库记录 | 不实时访问交易所；旧快照没有环境归属标记，换账户后需人工核对 |
| 权益曲线 | 最近288个 EquitySnapshot | 包含出入金影响，不当作策略收益或成交盈亏曲线 |
| 浮动盈亏 | Position.unrealized_pnl | 无记录或任一记录缺失时显示未知，不用0补齐，不与已实现盈亏合并 |
| 持仓数量、均价、杠杆、保证金 | Position 对应字段 | 数量标注合约张数；缺少合约规格，不推算基础币数量或名义金额 |
| 止盈、止损 | Position.tp_price / sl_price | 只是本地保护价格记录，不能证明算法单有效、数量匹配，也不能因缺失断言不存在 |
| 本地策略关联 | Position.strategy_id | 原同步代码可能按近期订单关联，因此只显示为本地关联，未核实 |
| 策略状态、模式、周期和交易对 | Strategy 原字段 | 启用不等于运行成功；不推测收益、胜率或排名 |
| 最近执行结果 | 每个策略最新插入的 StrategyLog | 区分持有、跳过、异常、已提交待确认；订单 ID 不证明成交 |
| 日志原文与模型置信度 | StrategyLog 原字段 | 保持转义，置信度注明非胜率，错误不隐藏 |
| 配置是否存在 | SystemConfig 的配置标志和原有安全视图 | 已配置不代表连接成功；密钥不回显，留空保留已保存值 |
| 运行/同步状态 | 原进程内 runtime_status | 重启后未知，不伪造持久化历史；显示错误并保留原数据 |

## 保留的操作与安全语义

- 不改策略判断、提示词正文、开平仓、预算、杠杆、保护单和实盘开关的业务逻辑。
- 不改模型、数据库表结构、现有配置、密钥、账号密码、会话、登录限制或鉴权中间件。
- 原有启停、单次执行、删除、平仓和环境切换仍调用原接口并保留确认步骤。
- 配置每区独立保存，密钥留空仍保留；账户测试使用已保存配置，Telegram 测试使用当前输入及原有回退规则。
- 未保存提醒只在内存记录修改标志，不向浏览器存储写入密钥、表单内容或提示词。
- 自动刷新在表单获得焦点、详情展开、弹窗或操作处理中暂停替换内容。普通分页禁用按钮不再误阻止刷新。
- 日志页面只读查询接受空策略筛选作为全部，避免 GET 表单提交空值导致错误；现有写入 API 未改变。

## 验证与预览

隔离测试覆盖展示空值、保留参数和提示词、配置分区、密钥不回显、日志转义、分页、读取页面不连接交易所、不写入业务记录、登录校验、未登录拦截及自动刷新阅读保护。

浏览器使用独立虚构数据预览，保留原登录鉴权；只允许登录提交，禁用策略调度、交易所连接和所有业务写入。已检查日夜主题、1440px桌面、1024px持仓平板布局、各页面390px手机布局、日志复制与分页、持仓详情和平仓确认取消。未确认或提交任何交易操作。

## 已知限制

界面优化不等于交易流程已修复。原有在线仓位限额、订单恢复及保护单生命周期问题仍在本次范围外，不能因此恢复无人监督交易。快照归属、保护单核实和策略成交归属仍受现有数据模型限制，页面如实标注未知，不自动补算。

当前持仓仍按原查询展示全部本地仓位，通常数量较少；本批只对运行记录增加10/20/50分页。未新增实时推送，也未更改交易所同步频率。

本次最终验证：74项隔离回归测试通过，新增共享脚本、设置脚本与监控脚本语法检查通过。开发中的首次版本发现的空策略筛选和分页按钮误阻断刷新已补充回归覆盖。原有依赖仍有弃用提示，本批未升级依赖或改变认证逻辑。
